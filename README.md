# 👾 崩壞狂奔 (The Glitch Run) - 賽博龐克風格網頁互動遊戲

> **「系統警告：代碼完整性嚴重受損。這座完美的虛擬城市正在崩塌，數據洪流開始失控……」**  
> 一款以賽博龐克與「故障美學（Glitch Art）」為核心概念的原創網頁遊戲。玩家將攜手神秘代碼夥伴「帕奇（Patch）」，在各大即將被刪除的虛擬分區中突破重圍、修復或利用 Bug，最終逃離造物主的刪除程序。

## 📖 故事背景 (Storyline)

在高度秩序化的數位世界中，廢棄代碼、被遺忘的角色與未完成的地圖碎片被堆積在底層。造物主啟動了清理程序 `SYSTEM_OVERRIDE`，企圖將所有「異常」徹底格式化。  
身為玩家的你，意外連結到了防火牆裂縫中的後門程式——**帕奇 (Patch)**。為了不被永遠困在數據迴圈中，你必須協助帕奇突破四道嚴密的系統防線，甚至「手動利用系統漏洞」開闢生路！

## 🎮 四大關卡機制 (Game Stages & Gameplay)

### 🧩 Level 1: 貪婪的商業區 (Sector 01 - Security Protocol)
* **玩法類型**：8-Puzzle 數字滑塊拼圖 + 即時回合制戰鬥
* **關卡首領**：貪婪主管（Capitalist Boss，以金錢符號 `$` 為象徵）
* **核心機制**：
  * **動態血量交互**：成功將拼圖數字歸位可對 Boss 造成大量代碼傷害；若移動錯誤導致順序打亂，Boss 則會藉由系統修復進度回血。
  * **時間懲罰**：每 3 秒扣除玩家 5 點生命值，逼迫玩家在倒數與 Boss 的嘲諷彈幕中快速解題。
  * **隱藏漏洞 (Hidden Bug)**：點擊 Boss 頭上的黃色便利貼 `[BUG]`，可直接解鎖後門覆寫權限，執行 `override_security.exe` 瞬間破解！

### 💖 Level 2: 廢棄的戀愛守則 (Sector 02 - Broken Heart Rule)
* **玩法類型**：彈珠打磚塊 (Breakout) + AVG 文字冒險對話
* **關卡角色**：被刪除的女主角（Glitch Girl）
* **核心機制**：
  * **情緒波動系統 (Anger Gauge)**：球掉落未接住會增加女主角的憤怒值；擊碎磚塊隨機掉落「回憶碎片」，可透過鍵盤選擇「溫柔安撫（降低憤怒）」或「現實激怒（增加分數但提高危險）」。
  * **狂暴變異**：當憤怒值突破 40% 時，角色立繪與全場景將產生強烈紅光與震顫變形（Glitch Mode）。
  * **火力支援模組**：接取隨機掉落的藥丸 `💊` 可啟動 6 秒連發射擊模式。
  * **摸頭殺彩蛋**：點擊左側女主角立繪，將觸發隱藏的「摸頭殺協議」，引發治癒聖光爆發，瞬間清空憤怒值並獲得大量分數！

### 🔄 Level 3: 無限的 Load 迴圈 (Sector 03 - Infinite Loading Loop)
* **玩法類型**：命運輪盤 (Lucky Roulette) + 5x4 記憶翻牌配對 (Memory Matching)
* **核心機制**：
  * **命運輪盤決定時限**：關卡開始前透過真實物理緩動輪盤與滾球動畫，隨機抽出 60 至 85 秒不等的通關限制時間。
  * **翻牌矩陣消除**：玩家必須在時限內將 10 組廢棄地圖與系統圖示完全配對消除。
  * **開發者漏洞**：畫面右上角藏有肉眼難見的微弱微光像素（`cheat-pixel`），點擊後即可執行強制垃圾回收指令 `GarbageCollection.exe --force` 自動翻開全場卡牌。
  * **維度崩壞過場**：通關後觸發經典藍屏當機（BSOD），畫面隨後如玻璃般破碎，角色直接「掉出遊戲外」，墜落至作業系統真實桌面！

### 🏃 Level 4: 桌面狂奔 (Final Sector - Desktop Glitch Run)
* **玩法類型**：橫向卷軸極速跑酷 (Endless Runner)
* **最終威脅**：造物主實體化的大手 (The Hand)
* **核心機制**：
  * **命運骰子擲定生命**：開局擲出動態骰子（1~6），隨機賦予本局的生命值（VIT）。
  * **跑酷跳躍**：按空白鍵跳躍閃避不斷襲來的代碼障礙物，累計分數達到 250 分即可逃離。
  * **被抓捕處刑**：生命值歸零時，造物主的大手將從天而降把主角連同殘骸抓起，扔進畫面左上角的「資源回收筒」徹底刪除！
  * **作弊晶片**：點擊畫面頂部的核心晶片（`core.png`），可進入鎖血無敵與超速加分狀態，直接破關。

## 🎨 視覺與特效設計 (Art & UI Features)

1. **多重渲染引擎風格切換 (Theme Engine)**：
   * 📟 **數據風 (Data)**：經典終端機深紫黑底配高對比賽博綠、青色霓虹，並疊加 CRT 掃描線動畫。
   * ✨ **明亮風 (Light)**：白底科技藍調，模擬企業內部現代軟體介面。
   * 💀 **黑暗風 (Dark)**：深紅警告配色，營造高壓故障氛圍。
   * 風格設定即時同步至 `localStorage`，跨關卡自動保存記憶。
2. **打字機沉浸式對話**：前言與劇情演出皆以純 JavaScript 逐字刻劃打字機動態，搭配光標閃爍效果。
3. **沉浸式過場演出**：運用 CSS `clip-path`、矩陣旋轉與漸層濾鏡，實現藍屏破碎、地圖雨墜落、紙堆升起等過場動畫。

## 🛠️ 技術實作 (Tech Stack)

* **核心技術**：原生 HTML5 / CSS3 / JavaScript (ES6+)，**無使用任何第三方重量級框架**，確保最純粹的前端運行效能。
* **視覺動畫**：
  * CSS Keyframe Animations (文字抖動、螢幕撕裂、彩虹流光、卡牌 3D 翻轉)
  * HTML5 Canvas API（Level 2 打磚塊物理碰撞、自訂彈道運算）
* **資料與狀態管理**：
  * DOM API 事件監聽與狀態機控制
  * `localStorage` 跨頁面狀態保持（主題設定）
  * 支援鍵盤（Space, Shift, Arrow Keys）與滑鼠混合操控

## 🚀 啟動與執行方式 (Getting Started)

1. **直接開啟**：
   * 下載本專案資料夾後，直接以現代瀏覽器（Chrome / Edge / Firefox）按兩下開啟 `index.html` 即可遊玩。
2. **開發伺服器啟動（推薦）**：
   * 使用 VS Code 開啟專案根目錄，右鍵點擊 `index.html` 並選擇 **「Open with Live Server」**，以獲得最完整的影音與過場載入體驗。
